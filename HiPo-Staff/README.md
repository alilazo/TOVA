# HiPo-Staff

HiPo-Staff means **High-Power Staff**. Each TOVA employee is defined by a versioned Markdown profile with validated YAML frontmatter and role-specific operating instructions.

The initial roster contains one Project Coordinator and six supporting specialists, for seven visible staff members total. Profiles are human editable and must follow `docs/STAFF_PROFILE_SPEC.md`.

Teams, tools, workflows, and templates will be added as typed Markdown catalogs in later phases. The Phase 1 web fixture mirrors the profiles in `staff/`.
